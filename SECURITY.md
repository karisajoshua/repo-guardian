# Security Policy

RepoGuardian is a defensive remediation planner. Do not submit credentials, private source, tokens or sensitive repository contents in issues or fixtures.

## Safety boundaries

RepoGuardian must not execute code from a target repository, push directly to a protected/default branch, silently choose a software license, or merge its own remediation. Proposed changes require human approval and should be delivered through reviewable branches and pull requests.

Report vulnerabilities privately through GitHub security reporting when available.
